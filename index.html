1. Initial Point Generation

1. 初期ポイント生成

Points can be generated by Admin or authorized users.

ポイントは管理者または権限を持つユーザーによって生成できます。

flowchart TD A[Admin or Authorized User

支店ポイント生成] C --> D[Insert Into cdt_pnt Table
cdt_pntテーブルへ登録] D --> E[Update Branch Balance
支店残高更新]

Endpoint

エンドポイント

POST /points/creditPoints

Request

リクエスト

  "divCode": "B1",

  "point": 10000
