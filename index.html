Point Flow System Documentation

1. Initial Point Generation

Points can be generated by Admin or authorized users.

flowchart TD A[Admin or Authorized User] --> B[Call creditPoints API] B --> C[Generate Branch Point] C --> D[Insert Into cdt_pnt Table] D --> E[Update Branch Balance]

Endpoint

POST /points/creditPoints

Request

{
  "divCode": "B1",
  "giverID": "admin",
  "point": 10000
}

2. Branch To Driver Point Transfer

flowchart TD A[Branch Manager] --> B[Call givePoints API] B --> C{Enough Branch Point} C -->|Yes| D[Transfer Point To Driver] D --> E[Insert giv_pnt] E --> F[Deduct branch_info] F --> G[Add driver_point] G --> H[Insert driver_point_record] H --> I[Success Response] C -->|No| J[Insufficient Point Error]

Endpoint

POST /points/givePoints

3. Driver Withdrawal Request

flowchart TD A[Driver] --> B[Call withdrawPointsRequest API] B --> C{Monthly Limit Exceeded} C -->|No| D[Insert req_pnt] D --> E[Create Withdrawal Request] E --> F[Success Response] C -->|Yes| G[Return Error]

4. Cancel Withdrawal Request

flowchart TD A[Driver] --> B[Call cancelWithdrawalRequest API] B --> C[Cancel Withdrawal Request] C --> D[Update Request Status]

5. Branch Manager Response

flowchart TD A[Branch Manager] --> B[Call responseWithdrawRequest API] B --> C{modReqPoint Value} C -->|Equal| D[Fully Approved] C -->|Zero| E[Rejected] C -->|Partial| F[Partially Approved] D --> G[Update req_pnt] E --> G F --> G G --> H[Response Completed]
